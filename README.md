## The Story Behind This Piece

Every brand starts as a signal — something unrecognised, unformed, just a pulse of potential in the digital noise.

This scroll experience tells that story.

As you scroll, a geometric aperture — cold, precise, scanning — slowly reveals itself to be something alive. It breathes open. It becomes a name. The name fragments into a constellation of services that Itzfizz offers. That constellation resolves, finally, into a real product: a browser window, a live site, a business that exists in the world.

**Signal → Identity → Presence → Interface.**

It's the same shape the whole way through. Nothing is swapped or replaced — everything *transforms*. That's the idea: Itzfizz doesn't build from scratch, they evolve what you already are into something undeniable.

---

## How It's Built

| Layer | Tech |
|---|---|
| Structure | Vanilla HTML5 |
| Styling | Vanilla CSS (custom properties, no framework) |
| Animation | GSAP 3 + ScrollTrigger (CDN) |
| Visuals | Inline SVG · Canvas API particles |
| Fonts | DM Sans · IBM Plex Mono (Google Fonts) |

No build tools. No framework. Just scroll.
